#### `ftp get`

*Исходная карточка: 2.5.8*

**Назначение**

ftp get Команда может использоваться для загрузки удаленных файлов и их хранения локально. (Применимо к IPv4)

**Синтаксис**

```text
Стандартный вид пользователя, вид глобальной конфигурации:
ftp get ipv4-address user password remotefile [ port-id ]
ftp get ipv4-address user password remotefile localfile filename [ port-id ]
Глобальный вид конфигурации:
ftp get ipv4-address src-ip src-ipv4-address vpn-instance name user password remotefile
ftp get ipv4-address src-ip src-ipv4-address vpn-instance name user password remotefile port-id
ftp get ipv4-address src-ip src-ipv4-address vpn-instance name user password remotefile localfile filename
ftp get ipv4-address src-ip src-ipv4-address vpn-instance name user password remotefile localfile filename port-id
```

**Значение по умолчанию**

Нет

**Командный режим**

Стандартный вид пользователя, вид глобальной конфигурации

**Рекомендации**

Во время фактической эксплуатации и обслуживания устройств часто возникает необходимость загрузить файлы конфигурации или файлы операционной системы с хост-компьютера на само устройство с целью изменения конфигурации или обновления операционной системы системы. Эта команда используется для загрузки файлов на устройство. Если параметр имени файла не указан, предполагается, что файл, загружаемый на устройство, имеет то же имя, что и файл на FTP-сервере. Перед использованием этой команды убедитесь, что интерфейс устройства подключен к хосту FTP-сервера и что на FTP-сервере настроены соответствующие имя пользователя и пароль.

**Пример использования**

```text
     Пользователь вошел на сервер по адресу 192.168.1.200, используя имя
пользователя 123 и пароль 123. Затем он загрузил файл с именем Switch.bin

с этого FTP-сервера и сохранил его локально, переименовав в v2.4.bin.

        Switch(config)#ftp get 192.168.1.200 123 123 Switch.bin v2.4.bin
        Getting File “Switch.bin” from 192.168.1.200...
        1528618 bytes downloaded.
        If you want to upgrade system,use “upgrade” command!
        Switch(config)#
```
