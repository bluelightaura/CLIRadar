#### `show ip config`

*Исходная карточка: 4.1.6*

**Назначение**

- show ip config — отображение информации о конфигурации IP-адресов.

**Синтаксис**

```text
show ip config
```

**Параметры**

```text
Параметр              Описание                 Допустимые значения
—                     Команда не принимает па- —
                      раметров
```

**Командный режим**

- Обычный пользовательский режим (user EXEC)

**Значение по умолчанию**

Не применимо.

**Рекомендации**

Команда используется для просмотра текущей конфигурации, связанной с IP-адресами, включая настройки ARP и интерфейсов.

**Пример использования**

```text
         Отображение конфигурации IP-адресов.

Switch> show ip config
!ip address configuration
outband ip address 10.18.12.120/24
!
!Ip Configuration
ip arp aging-time 600
Switch>
```
