#### `enable password`

*Исходная карточка: 2.1.11*

**Назначение**

enable password Команда может использоваться для глобальной настройки локального вторичного пароля аутентификации для уровней привилегий от 0 до 15.

no enable password Команда может использоваться для удаления локальных вторичных паролей аутентификации с уровнями разрешений от 0 до 15.

**Синтаксис**

```text
enable password level level-value cipher | plain password
enable password cipher | plain password
no enable password level level-value
no enable password
```

**Параметры**

```text
Параметр             Примечание                    Значение
                                                   Целочисленный формат
level-value          Уровень привелегий
                                                    со значениями от 0 до 15
                 Шифрованный текст пароля
                 или открытый текст,
{cipher | plain}
                 отображаемый в
                 командной строке
password         Пароль                            Формат строки
```

**Значение по умолчанию**

Нет

**Командный режим**

Глобальный вид конфигурации

**Рекомендации**

Использование вышеуказанной команды без указания значения уровня означает конфигурацию по умолчанию или удаление локального вторичного пароля аутентификации для разрешений уровня 15.

**Пример использования**

```text
        Настройка локального вторичного пароля глобальной аутентификации.

Switch(config)#enable password cipher password testkey
Switch(config)#
```
