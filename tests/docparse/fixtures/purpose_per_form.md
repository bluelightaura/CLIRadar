#### `clock timezone`

*Исходная карточка: 2.1.58*

**Назначение**

- clock timezone Команды могут использоваться для настройки информации о местном часовом поясе.

- no clock timezone Эта команда может быть использована для сброса локального часового пояса до часового пояса UTC (универсальное координированное время) по умолчанию.

**Синтаксис**

```text
clock timezone time-zone-name { add | minus } offset
no clock timezone
```

**Значение по умолчанию**

По умолчанию UTC +00:00.

**Командный режим**

Режим просмотра привилегированного пользователя

Нет
