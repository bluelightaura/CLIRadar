5.7.48 reset isis
**Command Function**
```
The reset isis command can be used to reset all or a single ISIS instance.
```
**Command Format**
```
reset isis
reset isis isis-instance
```
**Parameter Description**
```
Parameter Description Values
Isis-instance is the integer form of the ISIS instance number, with a range of 1 to 65535.
```
**Default Value**
```
None
```
**Command View**
```
Privileged User View, Global Configuration View
```
**Command Guidance**
```
None
```
**Usage Examples**
```
# Reset all ISIS instances.
Switch(config)#reset
isis Switch(config)#
```
