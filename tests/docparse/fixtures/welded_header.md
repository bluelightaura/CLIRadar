#### `clock set`

*Исходная карточка: 2.1.56*

**Назначение**

clock set Команда может быть использована для установки текущей даты и времени коммутатора.

**Синтаксис**

```text
clock set HH:MM:SS DD MM YYYY
clock set HH:MM:SS YYYY/MM/DD
```

**Значение по умолчанию**

Нет

**Командный режим**

Режим просмотра привилегированного пользователя

**Рекомендации**

В средах приложений, требующих строгого определения абсолютного времени, необходимо настроить текущую дату и время коммутатора. При вводе параметров времени поддерживается только 24-часовой формат. Компонент MM:SS может быть опущен, что означает 0 часов 0 минут 0 секунд. Однако для значения HH необходимо ввести как минимум одну цифру; например, ввод 0 означает 0 часов 0 минут 0 секунд. При вводе параметров даты год необходимо вводить в четырехзначном формате.
